## Penjelasan
Projek terdiri dari 4 file yaitu :
- App
- Player
- Pipe
- FlappyBird

Player dan Pipe adalah class atribut player dan pipe.App untuk memulai program dan FlappyBird untuk memodifikasi game

## Alur Program
- User menjalankan program, program game itu langsung bisa dimainkan
- Cara untuk memainkannya yaitu dengan memencet "Spasi" untuk menghindari dari pipa pipa
- Jika pemain terkena pipa maka permainan akan selesai
- Jika selesai pemain ingin memainkan gamenya lagi maka pemain bisa memencet "R" untuk memulai lagi permainannya
